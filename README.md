# Customer Directory

A simple Customer Directory built with HTML, CSS, and JavaScript.

# Features

- View customer list
- Search and filter customers
- View customer details
- Add new customers
- Validate customer information
- Fetch sample customer data using an API

# Technologies

- HTML
- CSS
- JavaScript
- JSONPlaceholder API

# JavaScript Concepts Used

Variables, arrays, objects, functions, conditions, loops, events, "map()", "filter()", "find()", JSON, DOM manipulation, and "fetch()".
